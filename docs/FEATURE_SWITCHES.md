# Feature switches

Every switch is a plain on/off value in `wrangler.toml`. Changing one needs a deploy from main (with the usual backup first).
All of them only show or hide things, EXCEPT `LATE_FEES` and `LATE_FEE_SPLIT`, the two switches that change money (see their rows). Last updated Thu Nov 5, 2026 (Tonight glow, Color cleanup and Simpler player cards added; earlier the same day Adjust credit, Venmo request and Home collapse; the two animation switches got Settings rows).
