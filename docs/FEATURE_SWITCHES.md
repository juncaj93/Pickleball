# Feature switches

Every switch is a plain on/off value in `wrangler.toml`. Changing one needs a deploy from main (with the usual backup first).
All of them only show or hide things, EXCEPT `LATE_FEES`, `LATE_FEE_SPLIT` and `SHORT_GAMES`, the three switches that change money (see their rows), and `CARD_CLEANUP`, which also changes who can join (no Max players cap, no waitlist; see its row), and `UNPAID_NUDGE`, which can refuse a player's own sign-up (see its row), and `ERROR_ALERTS`, which sends Alex Telegram messages (see its row).
