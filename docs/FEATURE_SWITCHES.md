**HOW THE VALUE IS READ (matches the code; if this ever disagrees with the code, the code wins).** Each switch has TWO layers: the `wrangler.toml` value (the kill switch, needs a deploy) and the Settings > Feature switches row (no deploy). For most switches a row only works if the kill switch allows it, and what a player or Alex sees is the Settings row (`MOTION` and `MOTION_ADMIN` are the exception, below).
- **Most switches are "allowed unless it says off".** The code is `(value ?? 'on').trim().toLowerCase() !== 'off'` (for example `lateFeesAllowed` in `shared/lateFees.ts`). So `"on"`, a missing line, a blank, `"false"`, `"0"` or a typo all leave the switch ALLOWED. Only the word `off` (any capitals) pulls the kill switch. That covers about 40 switches: every row of the table below EXCEPT the three named next.
- **Three read the word `on` the other way round.** `GO_LINKS` (`server/go.ts`: only the exact text `on` works; anything else, or a missing line, = the links answer 404), `MOTION` and `MOTION_ADMIN` (`shared/motion.ts`: the value, trimmed and in any capitals, must be `on` to switch it on for everyone; anything else or a missing line = not on for everyone, though the Settings row can still switch them on). Deleting one of those lines turns it OFF; deleting any other line leaves it allowed.
- **Three preview-only switches also need the word `on`** (trimmed, any capitals) and exist only in `[env.preview.vars]`, never production: `GAME_DAY_TEST`, `SECOND_CHANCE_TEST`, `PREVIEW_CALM`.
- **Everything else about a switch is the Settings row.** `wrangler.toml` can only forbid (set to `off`); it cannot turn a feature on for everyone on its own (except `MOTION`, `MOTION_ADMIN` and `GO_LINKS` above).
- **Where each switch stood on live:** read with the read-only PIN on Sun Nov 8, 2026, 7:05 PM Eastern (see the note in `scripts/preview-world-small.ts`), EVERY Settings row that existed then was ON for everyone (Short games, Late drops owe $14, Late-cancel fee split, Alert cards, Seat dots, the four speed rows, Game day card, Second Chance, After-game cards, Unpaid nudge and the rest). Rows added after that read were shipped OFF: Totals refresh (Zip 23), Error alerts (Zip 21), Booking hours (Zip 24) and Spent matches Totals (Zip 27). Their live state is NOT recorded here; read the Settings rows (or `npm run restore-test -- --live`, which lists the live rows in its NOTE) before relying on it.
